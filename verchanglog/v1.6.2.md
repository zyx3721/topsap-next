# v1.6.2

发布日期：2026-11-16

## 概述

TopSAP Client v1.6.2 修正 macOS 最低系统版本声明。v1.6.1 在 macOS 10.13.6 上双击启动即弹出「TopSAP Client 意外退出」：包内 `LSMinimumSystemVersion` 与 Mach-O `minos` 均为 10.13，但 Tauri 2.12.5 + wry 0.57.1 在 10.13 上执行 `WKWebViewConfiguration` 的 `drawsBackground` KVC 会抛出 `NSUnknownKeyException`。本版本将 macOS 最低版本提升到 13.0（Ventura），旧系统会在安装/启动前得到明确提示，而不是启动后崩溃。

## 变更

### macOS 最低系统版本提升到 13.0（Ventura）

- `src-tauri/tauri.conf.json` 新增 `bundle.macOS.minimumSystemVersion = "13.0"`；后续 dmg 会写入 `LSMinimumSystemVersion=13.0` 与对应 `MACOSX_DEPLOYMENT_TARGET`。
- macOS 10.13 / 10.14 不再进入启动流程；10.15–12 也不在本次支持范围。
- 未采用 Tauri 官方最低的 10.15：前端 Tailwind CSS 4 需要 Safari 16.4，而 macOS 10.15 的最终 Safari 为 15.6；10.15–12 即使绕过 wry 崩溃，也可能白屏或样式异常。
- 13.0 与 2017 款 MacBook Pro 的最高支持版本（Ventura 13.x）一致；建议更新到最新 Ventura（Safari 16.4+）。
- 同步更新 `README.md` / `README.en.md`、`docs/ARCHITECTURE.md`、`docs/CHANGELOG.md` 与 CI Release 平台说明。

### 文档与测试

- 修正 v1.6.1 发布产物文件名文档。
- 测试数据改用文档保留地址，不涉及运行行为。

## 根因说明

- 窗口配置设置了 `backgroundColor`，Tauri 将其同时传给原生窗口与 wry 的 `WebviewAttributes.background_color`。
- wry 0.57.1 在 `background_color` 存在时无条件执行 `WKWebViewConfiguration.setValue:forKey:"drawsBackground"`。
- `drawsBackground` 在 macOS 10.14+ 可用；10.13 的 `WKWebViewConfiguration` 不是 KVC-compliant，抛 `NSUnknownKeyException`，进程 abort。
- wry 0.54.2 / 0.55.0 曾有 `>=10.14` 保护，0.56.0 起丢失；上游 issue #1678 仍在跟踪未做版本保护的 WKWebView API。

## 用户影响与升级建议

- macOS 13.0+ 用户：正常升级安装；建议保持 Ventura 最新补丁。
- macOS 10.13 / 10.14 用户：v1.6.1 无法启动，请先升级到 macOS Ventura 13.x，再安装 v1.6.2。
- macOS 10.15–12 用户：建议升级到 Ventura 13.x；否则即使应用可安装，前端 WebView 也可能不满足 Safari 16.4 要求。
- Windows / Linux：不受本次变更影响。

## 验证

- `cargo check` 通过
- `src-tauri/tauri.conf.json` JSON 解析通过，`minimumSystemVersion = 13.0`
- `git diff --check` 通过
- v1.6.1 发布包核对：x86_64；Mach-O `minos=10.13.0`；`Info.plist` `LSMinimumSystemVersion=10.13`；包含 `drawsBackground` 字符串
- 未在真实 macOS 13 设备上复测 v1.6.2 安装包；macOS 数据面仍待真机回归

## 已知限制

- macOS 仍属「已实现，待真机验证」，本次只修正最低系统版本，不改变 TUN / helper / 路由实现。
- 不建议为 10.13 恢复支持：需要同时处理 wry `drawsBackground`、Vite target / polyfill 与 Tailwind 4 的 Safari 16.4 依赖，回归范围大。
- 若上游 wry 修复 10.13 保护，也只代表崩溃消失，不代表前端可在 10.13 渲染。
