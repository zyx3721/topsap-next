# v1.7.1

发布日期：2026-11-17

## 概述

TopSAP Client v1.7.1 调整启动时本机 DNS 预检的交互：开启「启动时自动连接」后，启动不再等待预检、也不再因检测到手动 DNS 而暂停，直接按设置发起连接；连接页告警卡片新增「跳过」按钮，可在保留手动 DNS 的情况下继续连接。预检本身保持不变，仍用于连接页告警。

## 变更

### 启动自动连接不再受手动 DNS 影响

- `autostart` 不再等待 `DnsPreflight::ensure()`，也不因检测到手动 DNS 暂停；校验连接配置、账号与已保存密码后延迟 800ms 直接调用 `Engine::connect`。
- 预检仍由 `lib.rs` 启动时提前执行，结果继续供连接页展示。
- 移除连接页「启动自动连接已暂停；改为自动获取后请手动点击『连接』」提示及对应文案。

### DNS 告警卡片新增「跳过」

- 「跳过」按钮位于「重新检查」右侧，未跳过时使用青色 `outline` 样式。
- 跳过后保留卡片并显示「已跳过本机 DNS 修改，将使用当前手动 DNS 连接；若连接失败请改为自动获取。」，按钮切换为绿色 `success` 样式并显示「已跳过」，同时解除连接与忘记密码门禁。
- 「重新检查」会重置跳过状态并重新检测；断开回到 `idle` 后自动刷新同样恢复告警。
- 连接门禁抽为 `src/lib/dnsGate.ts` 的 `isDnsGateActive()`，新增 5 项单测。

### 其他

- `Button` 新增 `success` 主题变体，基于 `ok` / `ok-soft` 颜色变量，适配浅色与深色主题。

## 已知限制

- Windows / macOS 真机上的启动自动连接与跳过交互仍需回归；macOS 本机无 SDK，平台分支待 CI。
- 跳过仅对当前预检结果有效，不提供持久化的「不再提示」；重新检查或断开后自动刷新会恢复告警。
- 修改本机 DNS 仍是持久操作，断开连接不恢复原设置。
