# v1.7.3

发布日期：2026-11-17

## 概述

TopSAP Client v1.7.3 在「设置」-「通用」新增「启动时检查本机 DNS」开关。开关默认开启；关闭后启动时不执行 DNS 预检，连接页也不显示 DNS 告警卡片。运行中关闭开关会立即隐藏告警，重新开启则等待下次启动才执行检查。

## 变更

### 新增启动时 DNS 预检开关

- 设置项 `dns_preflight_on_start` 默认 `true`，旧配置文件缺少该字段时自动按开启处理。
- 「设置」-「通用」新增「启动时检查本机 DNS」，位于「启动时自动连接」下方。
- 后端 `lib.rs` 启动时仅在开关开启时提前执行预检；`inspect_network_dns` 在开关关闭时直接返回空结果，不调用系统检查。
- 前端 `useDnsPreflight` 读取设置：关闭时立即清空告警与检查状态；运行中从关闭切到开启不立即触发，等下次启动程序后才检查。
- 连接与忘记密码按钮仍不受预检状态限制，保持默认可点击。

## 验证

- 按本次要求未执行 `cargo check` / `cargo test` / `npx tsc --noEmit` / `npm test`。
- 浏览器 mock 预览：
  - 开关默认开启，位于设置通用页；
  - 关闭开关后连接页 DNS 告警卡片立即消失；
  - 重新开启开关后不立即触发检查，卡片保持隐藏，需刷新页面（模拟下次启动）才重新预检；
  - 连接与忘记密码按钮始终可点击。

## 已知限制

- Windows / macOS 真机上的开关行为仍需回归；macOS 本机无 SDK，平台分支待 CI。
- 开关只控制启动预检；手动「重新检查」在开关开启时仍可随时执行。
- 关闭预检不会修改本机 DNS；手动 DNS 仍可能影响网关域名解析，连接失败会按正常流程提示。
