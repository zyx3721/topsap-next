# v1.7.5

发布日期：2026-11-19

## 概述

TopSAP Client v1.7.5 为连接后的资源列表补充置顶能力。鼠标悬浮资源卡片后可将其置顶到列表顶部的「置顶」分组，原分组中的资源位置保持不变；再次悬浮点击即可取消置顶。置顶状态保存在本机，重新加载或重新连接后自动恢复。

## 变更

### 资源列表置顶

- 资源卡片悬浮后，右上角显示置顶按钮：未置顶为 `Pin` 图标，悬浮提示「置顶」；已置顶显示 `PinOff` 图标，悬浮提示「取消置顶」。
- 点击置顶后，资源列表最上方新增「置顶」分组并显示数量徽标；被置顶的资源同时保留在原分组中，原分组展开/折叠状态不受影响。
- 没有任何置顶资源时，不渲染顶部「置顶」分组。
- 置顶与取消置顶按钮默认隐藏，仅在鼠标悬浮或键盘聚焦时显示；按钮与资源卡片分离，点击置顶不会触发打开资源。
- 搜索关键词同时过滤顶部置顶分组与普通分组；置顶资源不匹配时「置顶」分组隐藏。
- 置顶分组按最近置顶优先排序，普通分组保持原有排序规则。
- 中英文文案同步：分组标题中文「置顶」、英文 `Pinned`；按钮提示「置顶」/`Pin`、「取消置顶」/`Unpin`。

### 持久化与资源标识

- 置顶状态写入本机 `localStorage` 的 `topsap.pinnedResources`，重新加载并重新连接后自动恢复。
- 资源标识由「分组 + 名称 + 地址」组成，以 `\u0000` 分隔；同名但不同分组的资源可同时置顶、互不覆盖，字段边界重叠也不会产生相同标识。
- 读取存储时过滤非字符串与空字符串并去重；JSON 非法或存储不可用时回退为空数组；写入失败时置顶仅在本次会话内生效。
- 网关已不再下发的资源不展示，但置顶标识保留；同一资源重新下发时会恢复置顶状态。

## 验证

- `npx tsc --noEmit` 通过。
- `npm test`：10 个测试文件、84 个用例通过，其中新增资源置顶 10 个用例。
- `npm run build` 通过（tsc + vite 构建）。
- 浏览器 mock 预览：
  - 悬浮显示置顶按钮，点击后顶部出现「置顶」分组，原分组保留；
  - 再次悬浮显示取消置顶按钮，取消后顶部「置顶」分组隐藏；
  - 搜索过滤与中英文切换正常；
  - 完整刷新并重新连接后置顶状态恢复；
  - 临时加入数金总部、长亮控股两条同名同地址资源，同时置顶后顶部显示「置顶 2」，`localStorage` 中两条标识仅分组前缀不同，验证后已撤回 mock 数据。

## 已知限制

- 置顶状态仅保存在本机 WebView 的 `localStorage`，不随账号或网关同步；更换设备、清理应用数据后需要重新置顶。
- 资源标识包含地址；网关调整资源 URL 后，原置顶不会自动匹配新地址。
- 已下线资源的置顶标识会保留在本地存储中但不再展示，数据清理前不会主动删除。
