# v1.7.2

发布日期：2026-11-17

## 概述

TopSAP Client v1.7.2 移除 DNS 预检对连接与忘记密码按钮的限制。检测到手动 DNS 或预检进行中时，两个按钮默认即可点击；预检仍会执行并在连接页展示告警卡片，由用户自行决定是否先处理 DNS。

## 变更

### 连接与忘记密码按钮不再受预检限制

- 移除 `startupChecking`、`applying` 与未处理手动 DNS 对「连接」「忘记密码？」按钮的禁用逻辑；按钮只受连接状态与进行中的连接流程影响。
- 检测到手动 DNS 时不再显示「请先改为自动获取本机 DNS 后再连接」提示；登录卡片仅在首次预检期间显示「正在检查本机 DNS…」。
- 删除不再使用的 `src/lib/dnsGate.ts` 与对应 5 项单测。
- 告警卡片继续提供「改为自动获取」「重新检查」「跳过」；跳过仍保留卡片并标记已跳过，但不再承担解除门禁的职责。
- 启动自动连接保持 v1.7.1 行为：不等待预检、不受手动 DNS 影响。

## 验证

- `npx tsc --noEmit` 通过
- `npm test`：70 项通过（移除门禁模块的 5 项测试）
- 按本次要求未执行浏览器与真机交互验证

## 已知限制

- 连接时如果手动 DNS 影响网关域名解析，连接会按正常失败流程提示；用户可改为自动获取后重试。
- Windows / macOS 真机上的预检告警与直接连接行为仍需回归；macOS 本机无 SDK，平台分支待 CI。
- 修改本机 DNS 仍是持久操作，断开连接不恢复原设置。
