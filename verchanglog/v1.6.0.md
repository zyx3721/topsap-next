# v1.6.0

发布日期：2026-11-13

## 概述

TopSAP Client v1.6.0 为托盘图标增加连接状态提示：保留应用原图标的完整外观，只把盾牌主色按状态替换。未连接灰色、连接中蓝色、已连接绿色、正在断开浅蓝色、异常断开红色并闪烁。此前托盘图标始终是同一张彩色应用图标，窗口隐藏后无法从菜单栏判断 VPN 当前状态。

## 新增

### 托盘连接状态图标

- 图标直接使用应用原图标的完整像素内容：深色圆角底座、盾牌轮廓、齿轮细节全部保留，尺寸与原图标一致，不会变小或丢细节；仅把「青色盾牌」区域的像素替换成状态色。
- 五种状态：
  | 状态 | 颜色 | 表现 |
  | --- | --- | --- |
  | 未连接 | 灰色 `#8E8E93` | 启动后从未连接成功，或人为断开完成后 |
  | 连接中 | 蓝色 `#0A84FF` | 探测、登录、建链、重连过程中，静态 |
  | 已连接 | 绿色 `#34C759` | 当前隧道已建立，静态 |
  | 正在断开 | 浅蓝色 `#64D2FF` | 人为断开进行中，静态（不按异常提示） |
  | 已断开 | 红色 `#FF453A` | 掉线、自动重连关闭或重连失败等异常断开；约 0.7 秒在亮/暗红色间闪烁 |
- 状态由 `Engine::set_phase` 驱动：`Connected` 置为已连接并记录「曾经连接成功」，探测/登录/建链/重连阶段为连接中，`Disconnecting` 为正在断开，其余阶段按「是否异常断开」显示灰色或红色。
- 异常标记由引擎维护：只有掉线且自动重连关闭、或自动重连次数用尽时才标记异常；人为断开完成后回到灰色，不会误报红色。
- 连接页的状态卡与侧栏状态点同步采用同一套灰/蓝/绿/浅蓝/红（`StatusTone`），并区分「正在断开（浅蓝）」「异常断开（红）」「人为断开完成（灰）」。
- 闪烁由独立异步任务驱动，仅在「已断开」状态交替亮/暗（暗态为状态色按 0.55 压暗），其他状态保持静态并重置闪烁相位。
- 托盘 tooltip 同步显示「TopSAP Client · 未连接 / 已连接 / 已断开」。
- 状态用进程内原子量去重，阶段在连接流程中反复切换时只在状态真正变化时调用系统接口。
- 顺带修复设置保存的卡顿：保存设置后仅在代理绕过字段变化时才重查系统代理状态，避免连续切换开关时反复触发系统调用。
- macOS 显式关闭模板渲染（`icon_as_template(false)`，运行期替换后再设一次），避免状态色被系统按黑白模板抹平。

### 断线自动重连可配置与指数退避

- 设置新增「重连次数」：可自定义 1–999 次，或开启「无限次」持续重试。
- 退避改为真正的指数增长：2 / 4 / 8 / 16 / 32 / 60 秒，封顶 60 秒，并加入 ±20% 随机抖动，避免多客户端在同一时刻集中重连。
- 无限次模式下同样封顶 60 秒，不会无限增大；任何时候手动断开都会立即终止等待与重试。
- 重连等待改为可取消（`select!` 监听取消令牌），不必等满最长 60 秒才响应断开。
- 运行日志显示当前次数与本次间隔，例如「第 3/10 次重连尝试（间隔 8 秒）」「第 7 次重连尝试（不限次数，间隔 60 秒）」。

## 已知限制

- 图标尺寸沿用原应用图标像素，由系统缩放到菜单栏大小，未额外提供多倍图。
- 闪烁仅在「已断开」状态出现；连接中（登录/建链）按状态显示为灰色或橙色，不闪烁。
- 菜单栏图标在极端主题（如高对比度模式）下对比度可能降低，未做主题自适应。
